## 🛠️ Troubleshooting Common Issues

Most problems have simple fixes. Here are the most common ones:

### Strata won't start
- **Restart your computer** and try again
- Make sure you have at least 8GB of RAM
- If you have antivirus software, add Strata to its exceptions list

### Slow responses
- Close other heavy programs
- Check that you meet the minimum system requirements
- Responses will be faster on machines with 16GB+ RAM

### Image upload not working
- Ensure the image is saved locally on your computer
- Limit image size to under 10MB
- Try a JPG or PNG file

### Can't connect from another app
- Make sure Strata is running
- Check the API port number in Strata's settings
- Use `localhost` instead of `127.0.0.1`
